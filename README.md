# 🍛 Stuttgart Eats

A curated restaurant finder for international students in Stuttgart. Personally tested, honestly reviewed.

![Streamlit](https://img.shields.io/badge/Streamlit-1.30+-red)
![Python](https://img.shields.io/badge/Python-3.9+-blue)

## Why This Exists

When I moved to Stuttgart from India, finding good affordable food was harder than it should be. Google Maps reviews are noisy, food blogs target tourists with different budgets, and nobody tells you which place actually has good vegetarian options.

So I built this.

## Features

- **Filter by cuisine** — Indian, German, Korean, Thai, Italian, etc.
- **Budget filter** — under €10, €12, or €15
- **Dietary filters** — vegetarian, vegan options
- **Student-friendly tag** — full meal under €12
- **Honest personal notes** — not everything is amazing, but it's all worth trying
- **Sort by rating, price, or name**

## Currently: 17 restaurants across 9 cuisines

All personally visited or thoroughly researched. Ratings from Google Maps (early 2026).

## Run Locally

```bash
git clone https://github.com/aishwarya-sonawane/stuttgart-eats.git
cd stuttgart-eats
pip install -r requirements.txt
streamlit run app.py
```

## Want to Add a Restaurant?

Open an issue or PR. Include: name, cuisine, area, price range, rating, and your honest note.
